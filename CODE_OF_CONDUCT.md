# Code of Conduct

## Our pledge

We want AudienceMD to be a practical, respectful project for people who care about clear audience understanding, ethical communication, and useful tooling.

Participants are expected to be constructive, considerate, and direct without being hostile.

## Expected behavior

- Use welcoming and inclusive language.
- Respect different experience levels, backgrounds, and constraints.
- Give and receive feedback in good faith.
- Focus criticism on ideas, behavior, and project outcomes rather than personal attacks.
- Avoid manipulative, discriminatory, or demeaning language and examples.

## Unacceptable behavior

- Harassment, threats, insults, or sustained disruption.
- Sexualized language or attention.
- Publishing someone else's private information without permission.
- Discriminatory jokes, slurs, or exclusionary behavior.
- Bad-faith use of the project to stereotype, exploit, or manipulate audiences.

## Enforcement

Project maintainers may remove comments, close issues, reject contributions, or restrict participation when behavior conflicts with this code of conduct.

If you need to report a problem, use the current project contact path in [`SECURITY.md`](SECURITY.md) or the repository's public moderation/reporting features once available.

This code is adapted from the spirit of the Contributor Covenant, kept intentionally concise for this project's current size.
